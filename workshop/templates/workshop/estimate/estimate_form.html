{% extends 'workshop/base.html' %} {% load static %} {% block title %}{% if is_new %}New Estimate{% else %}Edit {{ estimate.estimate_number }}{% endif %}{% endblock %} {% comment %} ================================================================================ THE ESTIMATE FORM ================================================================================ Organised the way the Job Card is, because Office fills both and switching between two different arrangements of the same information is where mistakes come from. Same card-per-section shell, same `card-header bg-white` + blue `h6` heading, same `form-label small text-muted` labels, same `row g-3` grid. Four sections, in the order the printed sheet reads: 1. Vehicle Details make · model · reg · mileage · date 2. Customer name · phone · internal note 3. Job Needs To Be Performed descriptions, then ONE Total Labour 4. Part Name name · qty · unit price · amount The one difference from the Job Card is that **nothing here is required.** A quote is written with the customer standing there and is often half a car and two parts; a form that refused to save until every box was filled would be slower than the pad it replaces. Every field is `blank=True`/`null=True` at the model, so the only validation left is the pair that would produce a nonsense document: a priced row with no part name, and a negative figure. Two decisions worth not undoing: * **Part names come from a native ``, not the Job Card's fetch autocomplete.** The master spare list is ~200 entries, and a datalist needs no wiring — so a row added after page load gets the same suggestions with nothing to re-initialise. The Job Card's autocomplete needs a listener per input, which is exactly where its three documented cloning traps live. * **The unit-price hint is a PLACEHOLDER only** (see estimate.js). A price on a document handed to a customer has to be one a person decided. ================================================================================ {% endcomment %} {% block extra_css %} {% endblock %} {% block content %}
