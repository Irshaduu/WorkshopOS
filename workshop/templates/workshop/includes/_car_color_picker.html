It was inline in `jobcard_form.html` and is shared now because the Estimate needs the identical control. A second copy would be ~100 lines of markup, CSS and JS free to drift, on top of a palette that is already shared in Python (`CAR_COLOR_CHOICES` / `CAR_COLOR_HEX` in models.py). Three things about the mechanism, none of them obvious: * **The visible swatch is a `
`, not the field.** What posts is the hidden `{{ form.car_color }}` select beside it; the swatch is only a way of choosing. Hidden fields stay ENABLED on purpose — a disabled input is not submitted, so disabling them would clear the colour on every save. * **"Other" opens the browser's own colour input** and stores the resulting hex in `car_color_other`. `car_color_hex()` in models.py reads a leading `#` back out, which is why a literal hex is a valid value there. * **`.rainbow-dot` must be removed before a background colour will show** — it sets `background` with `!important`, so leaving it on makes every selection look like it did nothing. {% endcomment %}
